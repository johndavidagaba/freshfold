### One-Line Explanations of SEO & Metadata Tags

**Home Page SEO Tags (`app/page.tsx`):**
- **`title: "Laundry pickup in Yaba"`**: Defines the browser tab title and search result headline, combining with the root template to display as `"Laundry pickup in Yaba · FreshFold"`.
- **`description`**: Emits `<meta name="description">` providing search engine crawlers with the snippet text to display under the search result link.
- **`robots: { index: true, follow: true }`**: Emits `<meta name="robots" content="index, follow">`, explicitly instructing search engines to index the homepage and crawl its links.
- **`alternates: { canonical: "/" }`**: Emits `<link rel="canonical" href="/">`, establishing the definitive master URL to prevent duplicate content ranking penalties.

**Social / Open Graph Tags (`app/layout.tsx`):**
- **`metadataBase: new URL("http://localhost:3000")`**: Sets the root origin URL required by Next.js to resolve relative asset paths and canonical links.
- **`openGraph.title` & `openGraph.description`**: Emit `og:title` and `og:description` for social cards when links are shared on messaging apps (e.g., WhatsApp) and social networks.
- **`openGraph.type: "website"`**: Emits `<meta property="og:type" content="website">` declaring the object type to social graph scrapers.
- **`openGraph.siteName: "FreshFold"`**: Emits `<meta property="og:site_name" content="FreshFold">` showing the brand identity in preview cards.
- **`openGraph.locale: "en_NG"`**: Emits `<meta property="og:locale" content="en_NG">` indicating English (Nigeria).
- **`twitter.card: "summary_large_image"`**: Emits `<meta name="twitter:card" content="summary_large_image">` telling Twitter/X to render a full-width visual card preview.
