# Finding: the agent said "switching does not reload the page". The browser did not do a full reload,
# but every click still made a request to the server (one GET per switch), because changing the
# query string through the Next.js router re-requests the route from the server.

# Result: switching forms now makes zero server requests and no page reload.
# The URL still records which form is open, so the link can be shared or bookmarked.
