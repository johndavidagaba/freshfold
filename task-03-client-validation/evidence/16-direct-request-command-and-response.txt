# Windows PowerShell 5, curl.exe, dev server on localhost:3000

## Attempt 1: JSON inline
PS C:\Project\freshfold> curl.exe -s -i -X POST http://localhost:3000/api/signup -H "Content-Type: application/json" -d "{\"name\":\"a\",\"email\":\"not-an-email\",\"phone\":\"123\",\"password\":\"   \",\"terms\":false}"

# PowerShell 5 strips the backslash-escaped quotes when passing arguments to curl.exe, so the body arrived as
# invalid JSON. The route does not catch a JSON parse error, so it crashed with 500 instead of answering 400.
