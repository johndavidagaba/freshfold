PS C:\Project\freshfold> curl.exe -sS -i -X POST http://192.168.1.8:3000/api/signup -H "Content-Type: application/json" --data-binary "@b.json"

{"id":"cmvv5unvv0004v8p4f6uduh2j","email":"ada9@example.com"}

## (A badly timed check, kept for honesty: at ~17:03 localhost returned 201. Not a failure of the limit:

## 3. Clean re-run (~17:04 WAT): fill the localhost limit, then defeat it with a forged header
PS C:\Project\freshfold> 6..10 | ForEach-Object { ...signup ada2$_@example.com from localhost... }; ...signup spoof1@example.com with -H "X-Forwarded-For: 203.0.113.7"
localhost ada26 -> 201
localhost ada27 -> 201
localhost ada28 -> 201
localhost ada29 -> 201
localhost ada210 -> 429      <- limit reached (ada10 earlier + these 4 = 5 in the window)
fake header -> 201           <- same machine, same second, blocked one request earlier

# Two ways past the limit:
# (a) a genuinely different IP address: here my LAN address; in real life a phone hotspot, mobile data or a VPN.
# (b) a forged X-Forwarded-For header: the server trusts a header the client wrote itself. 203.0.113.7 is a
#     documentation address that never sent anything. Anyone with curl can be a "new visitor" on every request.
